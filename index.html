책갈피 — 일단 저장

다시 볼 페이지를 요약 없이 그대로 저장합니다. 글을 선택했다면 그 문장까지 함께. 툴바 버튼이나 우클릭 한 번이면 끝이라, 읽던 흐름이 끊기지 않아요.

형광펜 — 그 자리에 그대로

중요한 구절을 형광펜으로 칠하고 메모를 답니다. 저장한 하이라이트는 다시 방문해도 같은 자리에 다시 표시되고, 사이드패널에 기사별로 모여요.

기록 — 자동으로 쌓이는

요약한 결과는 따로 저장하지 않아도 날짜별 타임라인에 자동으로 쌓입니다. 사이트 파비콘과 함께 검색 한 번이면 "그때 그 글"을 바로 다시 찾아요.

모아둔 것을 더 쓸모 있게

폴더 + 태그로 정리

책갈피·기록·하이라이트 어디에든 📁 폴더 하나와 #태그 여러 개를 붙일 수 있습니다. 폴더·태그·검색을 조합해 쌓인 것들 속에서 원하는 것만 걸러 보세요.

읽기 리마인더

"나중에 읽어야지" 하고 잊지 않도록, 저장한 항목에 읽을 시각을 걸어 두세요. 시간이 되면 알림과 화면 카드로 알려 주고, 매일·매주 반복이나 10분 미루기도 됩니다.

노트 앱으로 내보내기

모아둔 책갈피·기록·하이라이트를 마크다운으로 다운로드하거나 클립보드로 복사해 노션·옵시디언에 그대로 붙여 넣으세요. 지금 보이는 필터 그대로 내보내집니다.

내 기록에 물어보기 + 학습 노트

"저번에 저장한 그 내용이 뭐였지?" — 쌓인 책갈피·기록·하이라이트에 질문하면 출처와 함께 답해 줍니다. 폴더·태그 범위를 골라 학습 노트로 정리할 수도 있어요.

글을 드래그하면 [요약]·[형광펜]·[책갈피] 툴바가 나타납니다. 칠하고, 저장하고, 필요하면 요약하세요. 우클릭 메뉴로 6가지 AI 모드도 쓸 수 있어요.

03

사이드패널에서 다시 찾기

툴바 아이콘을 누르면 책갈피·기록·하이라이트·노트 4탭 패널이 열립니다. 검색하고, 폴더·태그로 정리하고, 리마인더를 걸고, 노트 앱으로 내보내세요.

내가 읽은 것은 내 브라우저를 떠나지 않습니다

책갈피·형광펜·기록·노트는 전부 내 컴퓨터의 브라우저 저장소에만 저장되고, AI 요약도 기본은 Chrome 내장 AI로 기기 안에서 처리합니다. 외부 서버도, 로그인도 없어요.

저장도 처리도 로컬

회사 문서에 칠한 형광펜도, 개인 메일 요약도 밖으로 나가지 않습니다. 삭제·관리 전부 내 손에.

평생 무료

구독도, 광고도, 사용량 제한도 없습니다. 설치하는 순간 모든 기능을 그대로 쓸 수 있어요.

원하면 더 강력하게

옵션에서 내 OpenAI·Anthropic·Gemini API 키를 넣어 AI 기능을 더 큰 모델로 바꿀 수도 있어요. 선택은 자유.

자주 묻는 질문

정말 무료인가요?
네. 책갈피·형광펜·기록·노트·리마인더·요약·내보내기까지 모든 기능이 무료입니다. 결제 수단을 등록할 필요도, 사용량 제한도 없습니다.
제 데이터는 어디에 저장되나요?
책갈피·형광펜·기록·노트는 전부 내 컴퓨터의 브라우저 저장소에만 쌓입니다. AI 요약도 기본 설정에서는 선택한 글이 외부로 전송되지 않고 기기 안에서 처리돼요. 검색·삭제도 직접 관리합니다.
형광펜은 다시 방문해도 남아 있나요?
네. 칠해 둔 하이라이트는 같은 페이지를 다시 열면 같은 자리에 다시 표시됩니다. 메모도 함께 남고, 사이드패널에서 기사별로 모아 보거나 지울 수 있어요.
책갈피와 기록은 뭐가 다른가요?
책갈피는 요약 없이 페이지(와 선택한 문장)를 그대로 저장하는 "나중에 읽기"입니다. 기록은 AI 요약을 쓸 때마다 결과가 자동으로 쌓이는 타임라인이에요. 여기에 하이라이트(형광펜+메모)와 노트(학습 노트)까지, 사이드패널 4개 탭으로 나뉘어 정리됩니다.
저장한 걸 노트 앱으로 옮길 수 있나요?
네. 각 탭에서 마크다운 파일 다운로드 또는 클립보드 복사를 눌러 노션·옵시디언 등에 그대로 붙여 넣을 수 있습니다. 검색·폴더·태그로 걸러 둔 상태라면, 지금 보이는 목록 그대로 내보내져요.
AI 기능은 뭐가 있나요?
글을 선택하면 두괄식 요약(선택 없이 우클릭하면 페이지 전체), 우클릭 메뉴에서 작성·교정·말투·번역·물어보기, 단어 더블클릭 뜻풀이, 결과 읽어주기를 쓸 수 있습니다. 자주 쓰는 모드는 옵션에서 툴바에 추가할 수도 있어요.
더 똑똑한 AI를 쓰고 싶어요.
옵션 페이지에서 내 OpenAI·Anthropic·Gemini API 키를 입력하면 해당 모델로 전환됩니다. 이 경우 선택한 글이 해당 제공사로 전송되며, 안내에 따라 직접 선택할 수 있어요. 책갈피·형광펜·기록 저장은 이때도 내 브라우저에만 남습니다.
