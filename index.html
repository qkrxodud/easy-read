책

책갈피 — 일단 저장

다시 볼 페이지를 요약 없이 그대로 저장합니다. 글을 선택했다면 그 문장까지 함께. 툴바 버튼이나 우클릭 한 번이면 끝이라, 읽던 흐름이 끊기지 않아요.

형

형광펜 — 그 자리에 그대로

중요한 구절을 형광펜으로 칠하고 메모를 답니다. 저장한 하이라이트는 다시 방문해도 같은 자리에 다시 표시되고, 사이드패널에 기사별로 모여요.

기

기록 — 자동으로 쌓이는

요약한 결과는 따로 저장하지 않아도 날짜별 타임라인에 자동으로 쌓입니다. 검색 한 번이면 “그때 그 글”을 바로 다시 찾아요.

정

폴더 + 태그로 정리

책갈피·기록·하이라이트 어디에든 폴더 하나와 태그 여러 개를 붙일 수 있습니다. 폴더·태그·검색을 조합해 원하는 것만 걸러 보세요.

알

읽기 리마인더

저장한 항목에 읽을 시각을 걸어 두세요. 시간이 되면 알림과 화면 카드로 알려 주고, 매일·매주 반복이나 10분 미루기도 됩니다.

내

노트 앱으로 내보내기

모아둔 것을 마크다운으로 다운로드하거나 클립보드로 복사해 노션·옵시디언에 그대로 붙여 넣으세요. 지금 보이는 필터 그대로 내보내집니다.

찾

본문까지 뒤지는 검색

책갈피는 본문 스냅샷까지 저장돼 제목이 기억나지 않아도 내용으로 찾습니다. 초성 검색과 오타 허용에, 매치된 문장은 발췌로 바로 보여요.

요

두괄식 AI 요약

긴 글을 선택하면 결론 한 문장 + 요점 목록으로 정리해 줍니다. 우클릭 한 번이면 페이지 전체도 통째로. 결과는 기록에 자동 저장돼요.

세 단계면 끝.

01

익스텐션 설치

Chrome 웹 스토어에서 추가하면 준비 끝. 별도 설정이 필요 없습니다.

02

글을 드래그하면 [요약]·[형광펜]·[책갈피] 툴바가 나타납니다. 칠하고, 저장하고, 필요하면 요약하세요.

03

사이드패널에서 다시 찾기

툴바 아이콘을 누르면 책갈피·기록·하이라이트 3탭 패널이 열립니다. 검색하고, 정리하고, 내보내세요.

Knowledge Base

자주 묻는 질문.

정말 무료인가요?＋

네. 책갈피·형광펜·기록·리마인더·요약·내보내기까지 모든 기능이 무료입니다. 결제 수단을 등록할 필요도, 사용량 제한도 없습니다.

제 데이터는 어디에 저장되나요?＋

책갈피·형광펜·기록은 전부 내 컴퓨터의 브라우저 저장소에만 쌓입니다. AI 요약도 기본 설정에서는 선택한 글이 외부로 전송되지 않고 기기 안에서 처리돼요.

형광펜은 다시 방문해도 남아 있나요?＋

네. 칠해 둔 하이라이트는 같은 페이지를 다시 열면 같은 자리에 다시 표시됩니다. 메모도 함께 남고, 사이드패널에서 기사별로 모아 보거나 지울 수 있어요.

책갈피와 기록은 뭐가 다른가요?＋

책갈피는 요약 없이 페이지(와 선택한 문장)를 그대로 저장하는 "나중에 읽기"입니다. 기록은 AI 요약을 쓸 때마다 결과가 자동으로 쌓이는 타임라인이에요. 여기에 하이라이트까지, 사이드패널 3개 탭으로 나뉘어 정리됩니다.

더 똑똑한 AI를 쓰고 싶어요.＋

옵션 페이지에서 내 OpenAI·Anthropic·Gemini API 키를 입력하면 해당 모델로 전환됩니다. 책갈피·형광펜·기록 저장은 이때도 내 브라우저에만 남습니다.
